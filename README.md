# 💈 Бот онлайн-записи для салона / барбершопа

Telegram-бот, через который клиенты сами записываются на услуги, а администратор управляет расписанием прямо в Telegram.

## Возможности

**Для клиента**
- Пошаговая запись: услуга → дата → свободное время → имя → телефон → подтверждение
- Показываются только свободные слоты, прошедшее время скрыто
- Телефон отправляется одной кнопкой
- «Мои записи» с отменой в один клик
- Автоматическое напоминание за 2 часа до визита
- Прайс и контакты

**Для администратора** (`/admin`)
- Мгновенные уведомления о новых записях и отменах
- Расписание на любой день в виде сетки слотов
- Закрытие и открытие слотов (обед, выходной, личные дела)
- Отмена записи с автоматическим уведомлением клиента

**Надёжность**
- Защита от двойной записи на один слот (уникальный индекс в БД)
- Если слот заняли, пока клиент выбирал, бот предложит другой
- Все настройки бизнеса (услуги, цены, часы работы) — в одном файле `config.py`

## Стек

Python 3.8+ · aiogram 3 · SQLite (aiosqlite) · FSM

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Установите зависимости:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   pip install -r requirements.txt
   ```
4. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_ID`.
5. Запустите:
   ```bash
   python bot.py
   ```

## Структура

```
bot.py            — точка входа
config.py         — настройки бизнеса: услуги, цены, график
database.py       — работа с SQLite
keyboards.py      — все клавиатуры
reminders.py      — фоновые напоминания
utils.py          — даты и слоты
handlers/user.py  — сценарий клиента
handlers/admin.py — панель администратора
```

## Адаптация под заказчика

Достаточно поправить `config.py`: название, контакты, список услуг с ценами, рабочие часы и дни.
